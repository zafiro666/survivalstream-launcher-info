What the launcher does

SurvivalStream Launcher checks the files of the locally installed SurvivalStream modpack and starts Minecraft with that profile. The preview is being tested with Minecraft 1.21.1 and NeoForge. It is not available for public download.

Why we request Minecraft API access

Players sign in with their own personal Microsoft accounts in their default browser. The launcher uses Microsoft and Xbox authorization to sign in to Minecraft Services, verify access to Java Edition, and retrieve the player's Java profile before launch. It does not bypass the ownership check.

Account data

The launcher does not ask for or collect Microsoft passwords. The Microsoft sign-in session is stored locally using Windows-backed encryption. The Minecraft access token is kept only in the launcher's memory and passed to the local game process to sign in. Signing out removes the launcher's local saved session.

This website is informational only. It does not offer sign-in, request account details, or distribute game files.
